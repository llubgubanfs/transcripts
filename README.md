# Transcripts

Meeting and recording transcripts saved by the `/watch-ceb` skill, each with an executive summary.

- Files: `YYYY/YYYY-MM-DD-<slug>.md`, with YAML frontmatter (`title`, `date`, `type`, `tags`, `participants`, `source`, `transcriber`).
- Browse: [INDEX.md](INDEX.md), regenerated on every save.
- Search: `grep -l '^type: dsm' 20*/*.md`, `grep -l 'tags:.*gp-263' 20*/*.md`, `grep -ril '<word>' 20*/`.
